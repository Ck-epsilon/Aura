## 2026-10-23 · T2 / T28 与发布闸

- **终结符语言里，词法层必须知道“同一个字符的两种角色”。** Erlang 的 `.` 既是语句终结符又可能是小数点；词法器把 `1.` 吞成一个 number，函数跨度就永远收不了尾。判据：`1.` → 整数 1 + `.`，`1.0` → 浮点；修法是语言配置 `dotTerminatesNumber`，不是全局改数字扫描。证据：`f() -> 1.` 修前 `spanComplete=false`，修后 `function:f[1-1]`。

- **“可选段”的回溯必须是逐长度的。** 当字面量本身也在可选词表里（Rust `const` 同时是 modifier 与规则字面量），只试“全吃 / 不吃”会让 `pub const` 永远匹配不上；中间长度（吃 `pub`、留 `const`）才是解。证据：`pub const G` 修前 0 符号，修后 `variable:G`；`pub const fn` 仍是 `function:f`。

- **多子句函数按“第一个子句 + 到最后一个 `.` 的跨度”合并。** 后续子句以 `;` 开头；重复登记会造同名同跨度的假歧义（`target=f` → `STRUCT_AMBIGUOUS`）。证据：三子句 `f[2-6]`，`target=f` 命中 2-6。

- **测试的“没写真实 HOME”不能比对整棵共享目录。** 并行会话会正常写 `~/.aura/transactions`、`locks`、观测缓存；只盯被测安装器会写的 `~/.aura/{pkg,install.json,manifest.json}`，才既守边界又可重复。证据：整棵比对 10 次里 9 次红；收窄后 10/10 绿。

- **发布前必须确认“已发布字节 = 当前构建字节”。** npm 上的 0.7.0 适配器缺 `dsh/` 与 `dsh-shell` peer；本地 0.7.0 重建是另一份字节，同版不能重发。0.7.1 的拆包验收（75 项）与全量闸（exit 0）已覆盖这条。

## 2026-10-23 · 0.8.0–0.8.4 五版迭代

- **意图地址：先符号、后文本，结构歧义当场拒。** 多个符号候选时不能落到文本层——文本往往“恰好”命中其中一个，会把“有两个都可能”卖成“就是这一个”。证据：`intent-address` 31 项；`render` 两候选场景给 `LOCATOR_INTENT_AMBIGUOUS` 而不是静默命中。
- **改后坐标不能拿 `out` 的行数组直接算。** 片段层把 prefix/tail 拆成两个数组项，`parts.length` 不是行数；按逻辑行数 + 终态文本，才不会把行内替换误报成新增一行。证据：`receipt-context` C1/C5（`old: 'hello'` 修前 delta +1，修后 0）。
- **auto 的预算必须是宿主传进来的那个数。** 固定 8192 会把 6000–8192 字符的文件误判成“装不下”，多付一次回读；`budget - envelope allowance` 才是与渲染同一口径。证据：`auto-budget` A1/A3/A5。
- **任务级基准要量“读 + 改 + 回读校验”的总成本。** 单次调用快不是目标；成功率、调用数、token、返工才是。证据：`task-bench` 8/8 成功、每任务 2 次调用、950 token、返工 0。
- **发布物验证要真解包、真装、真跑，并比字节。** `tar` 在 Windows 上会把 `C:` 当远程主机；用相对路径 + `cwd` 解决。证据：`post-publish` 24/24，核心 20 文件/适配器 8 文件与本地派生包逐文件一致。
- **跨文件比对回执时只归一“句柄身份标签”。** 多目标与单目标测试用不同 identityKey/临时路径，身份标签不同是事实，不是渲染分叉；指纹与行号仍逐字比。证据：`multi-edit` A6/E3、`aura-edit/outcome` I1d 恢复绿。

## 2026-10-23 · 0.9.10 独立评审教训

- **把错误输出写成黄金期望的测试，比没有测试更坏。** 跨行 `old` 片段丢末行后缀，`old-fragment-fallback` 的 A3 直接把丢字节后的结果写成期望；全绿掩盖了数据丢失。判据必须来自“应该发生什么”，不是“当前发生了什么”。
- **功能内部的“探针读”不能改观测账本。** `suggestMode` 用 `readWith` 量 full 渲染长度，探针本身记录 delivery，导致外层 auto 把它当成 baseline，返回 56 字符的 “no change” 短回执。量尺寸的读必须 `probe:true`：不记账、不触发增量。
- **派生 metrics 必须进预算收敛。** 先渲染、后贴 metrics 会少算几十字节；8192 档实测被顶到 8250。所有会进入回执的字段都要参与 `sizeBy`。
- **候选地址必须是可执行地址。** 歧义回执把全局候选序号写成 `target=name#n`，同名/异名混排时多数解析不到；`#n` 只能按同名序号，唯一名字不带 `#`。
- **dry-run 不能产生“像真的一样”的副作用。** `--dry-run --transaction` 曾提交 0 文件事务，遮蔽真正的 undo；预演也不应铸可复用句柄（盘上没写，句柄必过期）。
- **锁文件“已存在但为空”不是陈旧锁。** 创建与写 PID 之间有窗口；把空锁当陈旧会抢锁，两个进程同时写。空锁需要短宽限；等待超时的错误消息也不能假设 holder 非空。

## 2026-10-23 · 0.10.1–0.10.5 内置替代与复审

- **观测缓存的上限不能把令牌一起丢掉。** 旧 `remember` 对 >256 KiB 的源整条 return，严格新鲜度因此永远拿到 `never-read`，而它要求的恢复动作（先读一次）不可能成功。令牌与全文是两件事：超限只丢全文，`regionGate` 退回 `basis:'none'`，严格闸仍能回答“这一版读过没有”。证据：262145 字节文件 read 后 write 仍被拒；修后通过。
- **整份替换的行区间必须来自规划那一次读。** 先读一次算总行数、规划时再读一次，两次之间文件变长就会只替换前缀、把旧尾巴留在盘上（`allow_unobserved` 下无观测闸兜底）。证据：单读 provider 的 `readsAtWrite === 1`；旧实现是 2 次。
- **逃生口必须同时越过它要绕过的所有闸。** `allow_unobserved` 只关严格闸、不关区域闸时，“读过旧版后文件又变”的场景仍然写不进去；旗标名承诺的是盲写，不是“只对从未读过的文件有效”。
- **`dry_run` 要在规划阶段就分支，不能只在写盘函数里判。** `create` 路径返回 `dryRun:false` 且写盘阶段不看旗标，于是 `edit --create --dry-run` 真的建了文件。预演的判决必须覆盖 create/patch 两条路。
- **片段层“末列”不能猜。** 无条件吞掉与末字相同的后续字符，会让 `old:"ax "` 吃掉两个空格、`old:"a"` 在 `aa` 上吃掉整段。只替换命中跨度本身；需要容错时由 norm-space 层负责。
- **元素级参数要在归一化层显式转发。** `targets` 元素的 `require_observation` 被收下却在 `editTargetRequests` 前丢掉，回执还成功；顶层默认值不能替代元素显式值。同一形状在 `dryRun`/`identityKey` 上已有先例，新增键必须进同一张转发表。
- **`replace_all` 不接受首/尾换行的 `old`。** 片段层会剥掉首尾换行，`old:"a\n"` 于是退化成全文子串搜索（`banana` 也中），从“改一行”变成“改一片”。这种形状要拒绝并让调用方去掉换行。
- **契约变强后，旧的降级断言要重写而不是删掉。** >256 KiB 从“不记观测”改成“记令牌不存全文”后，三条 `unverified_region` 断言不再成立；保留“外部改动后降级”的那条，另加“读后未变不降级”，才既符合新契约又没有丢掉边界覆盖。
- **给现有插件加第二个工具时，先查测试怎么取“那个工具”。** 多个壳套件用“最后一次 `register`”当 `aura_edit`；把 `aura_write` 注册在它之后会让所有既有断言悄悄测错工具。注册顺序（write 先、edit 后）与按名捕获（`tools.get` / 测试里的 name map）要一起改。证据：`aura-edit/load` 74/74、`real-framework-smoke` 29/29。
- **提示段里的“兜底工具”要随能力一起改。** DSH 已经注册 `aura_write` 后，`aura_edit` 的提示仍写“整份覆写用内置 write”，模型会继续走旧路径；工具存在不等于会被用，提示词与命令式措辞是采用率的一半。证据：`tool:aura-write` 段与 `tool:aura-edit` 末句同批更新。

## 2026-10-23 · 0.11.0 静默语义审查

- **“参数表里没有”不等于“参数会被拒”。** CLI 的 `flag()` 只找已知旗标、MCP 只读自己认识的键，于是 `--dryrun` / `dryrun:true` 被静默忽略后**真写盘**。判据必须是“未知键 ⇒ 拒绝且不写盘”，合法键从 schema/共享常量派生；`targets` 元素也逐个校验。证据：`argument-surface` 17/17。
- **符号投影只有行号时，`target` 的“整行区间”不是符号的区间。** 压缩 JS 里两个顶层函数同为 1-1，`target=alpha` 会把 `beta` 一起删掉；lone CR 文件整份只有一行，`target`/`lines` 会替换整个文件。拒绝码 `LOCATOR_LINE_SHARED` / `LOCATOR_LONE_CR`，并让 `old` 片段与显式整份写成为出口。证据：`single-line-target` 12/12。
- **回执必须在事务回滚之后重建。** 引擎先写回执、事务层后回滚，旧版把回滚前的 `landed/applied/landed_paths` 原样返回——磁盘已恢复，回执还说“改成了”。判据：`applied:0`、`landed:false`、`landed_paths:[]`、`rolled_back:true`，且 `rollback` 不依赖 `include_transaction`。证据：`standalone` O7 扩充断言。
- **并发观测缓存必须 read-merge-write。** 两个 CLI 进程各自“启动读整份、结束写整份”，后写覆盖先写，随后对先读文件报 `never-read`。锁 + 合并 + 查询前刷新；证据：`observation-concurrency` 两进程/六进程 9/9。
- **“0/0 通过（已跳过）”不是通过。** 闸自己的统计口径也要被审查：跳过记 `⏭`，关键套件跳过记失败；CI 的 Linux full-gate 与 Node 18/20 smoke 是这条判据的执行面。证据：`ci-contract` 16/16，`installed-package` 现显示 `⏭`。
