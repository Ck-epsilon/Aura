# aura-tools 0.5.3 —— Haskell 修好，21 种目标格式**全部登记**

## 新增守卫：`guard: 'topLevel'`（第一列 layout 闸门）

Haskell 的顶层绑定**没有关键字可锚定**：`beta a = a + 1`（顶层）与 `a = a + 1`（函数体内）在 token 流上完全同形，
唯一的硬差别是 **layout 规则——顶层绑定的名字在第一列**。引擎里本来就有做这件事的判据
（`clauseInitial`：这个 token 是不是该行第一个），但 `matchRule` 拿不到行号信息，所以加了一个参数把
`lineAt` 传进去，并新增 `guard: 'topLevel'`。

## 两件修法一起用上（缺一不可）

1. **`guard: 'topLevel'`** 去掉**假符号** `a@4-4`（旧规则把函数体内的 `a = a + 1` 当成顶层绑定）。
   假符号比没符号危险——`target=a` 会改到参数身上；
2. **去掉 `::` 类型签名规则**：`beta :: Int -> Int` 与实现 `beta a = a + 1` 同名，两条规则会造出
   `STRUCT_AMBIGUOUS`（`target=beta` 直接不可用）。代价：只写签名的接口文件不再出符号——如实记录。

函数规则同时改成 `['$nameNotKeyword', '$ident*', '=']`：`$ident*` 接住裸参数（Haskell 的参数不是括号组，
旧规则 `['$nameNotKeyword','$param','=']` 永远匹配不上），且它**不是**模式最后一个元素（后面还有 `=`），
不会退化成"跳一个可选括号组"。

**实测**：`a.hs` → `beta@4-4`（只剩实现那一个符号），`target=beta` **成功**；
`lang 21/21`、`struct 28/28`、`corpus 287 文件 0 坏`、`span-fidelity 95/95`、`read2 59/59` 全部复跑通过。
