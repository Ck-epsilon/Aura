# aura-tools 0.5.1 —— 主代理接手：Nim 与 Zig 落地（语言表 62 → 64）

**背景**：0.5.0 发布时 `hrl`/`nim`/`zig` 三种格式**未登记**（子代理在跨度判据上连续失败 5 次以上，
按熔断规则停手并交了根因）。这一版由主代理接手，**用两次实验找到了两条写法**，把 `nim` 与 `zig` 修好：

## 修好的两种（实测）

| 格式 | 夹具 | 实测 | 关键写法 |
| --- | --- | --- | --- |
| `nim` | `proc alpha(a: int): int =` + 缩进体 | `alpha@1-2`，`target=` 成功 | **缩进体语言（`bodyOpen: null`）不能把终结符写进模式、也不能加 `guard: 'body'`** —— 终结符交给 `blockEnd.headerEnds`（Nim 已配 `['=']`），`guard: 'body'` 只适用于大括号体 |
| `zig` | `fn alpha(a: i32) i32 { … }` / `fn beta() void { … }` / `fn gamma() { … }` | `alpha@1-3` / `beta@1-3` / `gamma@1-3`，`target=` 均成功 | **块开符不能写进模式** —— 交给 `bodyOpen` 判（这正是 C 家族的写法） |

两条都不是"新原语"，是**既有原语的正确用法**；之前失败的原因是写法与语言形态不匹配：

- Nim 旧规则 `['proc','$name','$param','=']` 永远匹配不上：参数表与 `=` 之间还夹着**返回类型** `: int`，
  而 `:` 不是标识符、现有原语都跳不过它；
- Zig 旧的三条规则都写了 `{`；`$ident*` 放在 `$param` **之前**或写在模式**末尾**时都会退化，匹配不上。

**并且没有靠"给夹具补内容"凑绿**：靶场元数据按实测翻成 `indexed: true` + `sym`/`span`，
格式靶场 **3300/3300 全绿**；`lang-test 21/21`、`struct-test 28/28`、`corpus 287 文件 0 坏`、
`span-fidelity 95/95`、`read-test 33/33`、`layers 29/29`、`regex-lex 51/51` 全部复跑通过。

## 仍然没修好的（如实）

- **`hrl`（Erlang 头文件）**：`.hrl` 的常见形态是 `-define(NAME, 1).` / `-record(name, {...}).`，
  名字与 `)` 之间夹着「**逗号 + 字面量**」，而现有原语（`$param` 跳括号组、`$ident*` 吃标识符、
  `$mods*` 吃词表、`$label` 捕字符串）**都跳不过它**。两种写法都实测过：加 `')'` 匹配失败；不加则拿不到符号。
  **正确修法**（留给下一轮）：给匹配器加一个"跳到当前括号组收尾"的原语（例如 `$rest`），
  或让 `declarationSpan` 容忍未闭合的组。属**引擎原语层**改造，不是配置能补的。
  → 因此 `hrl` 继续**不登记**（登记会让"格式认得出来但索引不出东西"与"根本不认识"两种失败混在一起）。
- **`erl` / `hs`**：登记但符号不可用（`erl` 只出 `module:` 属性、`hs` 跨度不完整且会把形参当假符号）。

## 覆盖现状（21 种目标格式）

- **已登记 20/21**（只差 `hrl`）；
- **符号表 + `target=` 实测可用 17 种**：`sql graphql gql tf vue svelte astro`（批 1）、
  `r ex exs clj cljs el vim cython ml`（批 2）、**`nim` `zig`（本版）**；
- 语言表扩展名总数：44（0.4.2）→ 62（0.5.0）→ **64**（本版）。包内 README 里的数字**由引擎语言表动态渲染**，
  不需要手改（这条机制在三次数字变化里连续自证）。
